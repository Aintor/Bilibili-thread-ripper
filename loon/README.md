# 哔哩速度 · Loon 手机端智能选路插件

基于「哔哩速度」核心流媒体算法打造的 iOS Loon 专属插件。

通过在 **`PlayViewUnite`** 协议层无损重构播放清单，彻底规避 403 鉴权报错，实现起播零延迟、全天候稳定命中当前网络下最快官方 CDN。

---

## 核心特性

- ⚡️ **Donor（供体）跨节点合成**：从官方下发的任意正规节点中提取合法 Token，主动合成包含阿里、腾讯、华为、香港 Equinix、海外 Akamai 等 10+ 个顶级正规 CDN 的完整矩阵，塞满手机 App 原生并发池。
- 🛡️ **PCDN / MCDN 彻底清洗**：自动识别并强力拔除 `*.mcdn.bilivideo.cn`、`/v1/resource/`、`os=mcdn` 等所有利用用户上传带宽搭建的劣质边缘节点。
- ⏱️ **0 毫秒异步智能测速**：后台探针定期测速主流节点往返延迟（RTT），存入本地存储；视频播放时 0 毫秒直接读取最优冠军节点，杜绝现场测速导致的起播转圈黑屏。
- 🚫 **零代下、零发热**：坚决不在代理层做高开销的切片代下，保持 iOS 原生 HTTP/2 长连接与多路复用，耗电与内存开销几乎为零。

---

## 安装与使用 (Loon)

### 1. 导入插件
打开 iOS **Loon** App，进入 **「插件」 (Plugin)** 标签页：
1. 点击右上角 **「+」** 或 **「从 URL 添加」**；
2. 粘贴以下插件订阅链接并保存：
```text
https://raw.githubusercontent.com/Aintor/Bilibili-thread-ripper/main/loon/bilibili-speed.plugin
```

### 2. 证书与 MitM 检查
确保 Loon 已经开启 MitM，且证书已被完全信任：
* iOS **「系统设置」** -> **「通用」** -> **「关于本机」** -> **「证书信任设置」** -> 勾选信任 Loon CA 根证书。

### 3. 即刻体验
* 打开手机 B 站 App，播放任意高清/4K 视频，体验秒开与流畅加载！
* 在 Loon 中可随时进入 **「任务」 (Tasks)**，找到 **「哔哩速度 · CDN测速探针」** 点击 **「立即运行」**，即可在手机通知栏查看当前网络下各 CDN 的实测延迟与最优排名。
